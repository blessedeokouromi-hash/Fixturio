Advertising settings

Turning ads on activates every zone you have filled in. Empty zones do nothing, so the site stays clean until you add real network code. Popunders are capped at one per visitor per day, and the social bar and banners show once per page. Every impression pings the tracker for later revenue reporting.

One-time setup (Vercel)

1. In Vercel, open your Fixturio project → Settings → Environment Variables.

2. Add ADMIN_TOKEN with any secret phrase you choose. That is the password for this page.

3. Add GITHUB_TOKEN with a GitHub personal access token that has write access to the Fixturio repository (repo scope). That is what lets this page save settings.

4. Redeploy once. After that, this page can switch ads on and off and paste your Adsterra zone links, and every save redeploys the site automatically.
